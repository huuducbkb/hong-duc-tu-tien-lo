# HỒNG ĐỨC TU TIÊN LỘ

HỒNG ĐỨC TU TIÊN LỘ là game Text RPG Tu Tiên kể chuyện bằng AI, đồng nhân Phàm Nhân Tu Tiên. Người chơi có thể nhập hành động tự do hoặc chọn hành động do AI đề xuất.

Mỗi chương có 11 nút xương sống. Game theo hướng hardcore: chết là mất save.

Chơi tại: https://huuducbkb.github.io/hong-duc-tu-tien-lo/

Trạng thái: đang xây dựng lại từ đầu.
